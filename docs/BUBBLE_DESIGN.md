# OMP Pet 气泡设计

2026-09-18 用户确认：主气泡 Noto Sans SC，子代理微软雅黑。使用均匀的纯黑微透明表面，不加反光、高光渐变、发光边框或文字阴影。

## 字体与密度

- 主气泡内置完整 Noto Sans SC 可变字体，标题 13px / 500，状态与说明 11px / 400。
- 子代理与组摘要使用系统 Microsoft YaHei，11.5px / 400；时间随所在气泡使用同族，10.5px、等宽数字。
- 保持正常字距，禁用合成粗体。
- 主标题与计时同一行，状态与说明在下一行；长内容自动增高，主标题和说明各最多两行。
- 主气泡上下留白 10px、左右 18px，为胶囊两端预留文字安全距离。
- 子代理默认单行，展开后显示完整标题和详情；整组仍可堆叠收起。普通子代理最小高度 34px。

## 表面与轮廓

- 统一由 WebView 绘制黑色 82% 不透明度的表面，轻微透出桌面；文字与宠物保持原本不透明度。没有额外桌面模糊。
- 边框由独立 SVG 矩形绘制为单层 1.5px 不透明实线：主气泡 #85858b，子代理 #77777d。保留 1px 透明布局边框，避免改变气泡尺寸；没有叠加内沿、发光或虚线。尾巴放在边框外，不遮断底边。
- SVG 描边外沿向内对齐设备像素，避免小数行高导致整圈半像素偏移；圆弧和直线使用同一条闭合轮廓、同一线宽。保留正常抗锯齿以避免锯齿，1.5px 描边增强圆弧的实心部分。
- 主气泡固定圆角 32px，子代理和摘要固定 17px：默认高度为胶囊形，自动增高或展开时保持半径，两侧延长直线，不随高度放大圆弧。展开列表间距 4px，主气泡与组间距 10px。
- 收起后显示两个完整的 34px / 17px 半径胶囊背层，各向内缩 6px、向下错位 8px；每层仅露出前层下方的 8px 弧面，绝不覆盖前层底边。
- 堆叠背层使用真实 DOM 和裁剪容器，原生区域直接读取其完整轮廓与可见窗口，避免伪元素几何推算造成断线；点击露出的背层同样展开列表。
- 保留错误、等待确认等语义状态点，普通任务使用低亮度灰点。

## 工程约束

- 不创建独立原生亚克力底衬窗口：该合成效果在本机圆角外残留矩形背景。保留原生裁剪、窗口装饰过滤、DWM 边框禁用和 GDI 背景清理。
- 不添加超出原生区域的外阴影。
- 原生圆角裁剪先外扩 2 个物理像素，再限制在原气泡矩形和滚动视口内，保留圆弧与切线处的抗锯齿像素；可见轮廓由 WebView 内的 SVG 绘制。
- 字体在程序内离线加载；完成加载时重新测量动态高度。
- Noto Sans SC 的许可证同时随前端资源和发行包 docs/NotoSansSC-OFL.txt 提供。
